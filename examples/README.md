# Example inputs

`beta_catenin.fasta` is the 556-residue project construct used to prepare a real single-protein AF3 data-pipeline input.

`toy_msa_data.json` is an artificial 9-residue protein with a query-only alignment and no templates. `toy_ligands.csv` contains four simple molecules for validating the input generator. They are not the screened compound library and are not proposed β-catenin binders. The SMILES in this CSV are accepted input strings; `build_jobs.py` does not recanonicalize an externally supplied CSV.

```bash
python scripts/build_jobs.py --msa-json examples/toy_msa_data.json \
  --ligands-csv examples/toy_ligands.csv --out-dir demo_inputs \
  --seeds 1 --round seed_1
```

Inspect `demo_inputs/jobs/000/bcat_lig_000001_seed_1.json` and the relative MSA path. No AF3 execution is needed. The generated bundle is ignored by Git. The separate `scripts/demo.py` creates artificial **outputs** for postprocessing tests; those output coordinates are not generated by AF3 from these example inputs.
